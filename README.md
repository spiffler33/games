# games
Making games which me and kids can play

## 🎳 Strike! Bowling

A touch-first bowling game for kids, built for iPhone (works on any phone or desktop browser).

**▶️ Play it here: https://spiffler33.github.io/games/**

### How to play

1. Open the link on your phone
2. Slide your finger left/right to position the ball
3. **Flick up** to bowl — flick harder for more power, curve your swipe to hook the ball!
4. Knock down all 10 pins for a STRIKE 💥

### Features

- 🎯 Real 10-frame bowling scoring (strikes, spares, 10th-frame bonus balls)
- 👧👦 1 or 2 players with names and animal avatars
- 🛡️ **Bumpers mode** — no gutter balls (on by default, great for younger kids)
- 📱 **Tilt steering** — turn it on and tilt the phone to steer the ball mid-roll (uses the gyroscope)
- 🔊 Sound effects + a voice announcer that cheers for strikes and spares
- 🎉 Confetti, celebration banners, and a trophy screen
- 🏆 High score saved on the device
- 📲 **Add to Home Screen** for a full-screen app experience (Share button → "Add to Home Screen")
- ✈️ Works offline after the first visit — great for car rides
- 💤 Keeps the screen awake while playing

### Tech

Plain HTML/CSS/JavaScript + Canvas. No frameworks, no build step, no dependencies.
Deployed automatically to GitHub Pages via GitHub Actions.
Icons are generated by `tools/gen_icons.py` (pure-Python PNG writer, no deps).
